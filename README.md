## Instalação

Todas as instalações abaixo são referentes ao Ubuntu

### Instalar o compilador GCC

Certifique-se de que você tem o GCC instalado:

    $ sudo apt update
    $ sudo apt install build-essential

## Uso

Entre no diretorio via terminal

    $ cd Morse_code_interpreter/

### Compilar o programa

    $ make

### Executar a aplicação

    $ ./morse "NOME DO ARQUIVO DICIONARIO"
